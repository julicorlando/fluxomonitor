API de contagens

Base: https://fluxo.axionwebdigital.com.br · autenticação Authorization: Bearer TOKEN. Tokens de dispositivo ficam limitados ao dispositivo associado.

MétodoEndpointResultado

Análise e comparações

GET /api/v1/insights/?mode=month&date=2026-10-15. Modos: day, week, month e year. Filtros device e group; comparison=previous, week ou year; compare_date para escolher outra referência. No dia, grain=15 ou 60. Use format=csv para exportar. O escopo do token é preservado.

A resposta inclui current, previous, difference, variation, warnings, missing_devices e pending_imports. Períodos em andamento comparam o tempo transcorrido. Cobertura não é certificada; ausência de registros não confirma fluxo zero. A análise consulta somente o banco e não altera os equipamentos.

Exemplo Python

import os, requests
response = requests.get(
    "https://fluxo.axionwebdigital.com.br/api/v1/devices/1/",
    headers={"Authorization": "Bearer " + os.environ["FLUXO_TOKEN"]},
    timeout=10,
)
response.raise_for_status()
print(response.json())

Power BI

Use Obter dados → Web para o endpoint desejado. No modo avançado configure o cabeçalho Authorization com Bearer e seu token de consulta. As leituras retornam uma lista em readings. Preserve os horários com fuso ao transformar os dados.

Protocolo PanPanTech PFC · JSON

Envio nativo: /api/camera/dataUpload/TOKEN e heartbeat /api/camera/heartBeat/TOKEN. Token de recebimento vinculado ao dispositivo e serial cadastrado são obrigatórios. O segredo no caminho é alternativa ao Bearer para firmware que não permite cabeçalho; use na rede interna e não divulgue as URLs.

Intervalo 0 no equipamento = tempo real. Janelas são substituídas por sn + endTime quando time aumenta, sem acumular reenvios. A resposta retorna code 0, msg success e data com serial e horário Unix do servidor. Passby, turnback, faixas de altura e eventList ficam preservados no registro nativo. Eventos ainda não são usados para fracionar as janelas por hora.

Envio

{"device_id":1,"event_id":"unico-estavel","timestamp":"2026-10-14T10:00:00-03:00","entries":10,"exits":4,"mode":"delta"}

mode delta = intervalo; cumulative = acumulado. O primeiro acumulado é referência. HTTP 201: criado; 200: reenvio idêntico; 202: JSON nativo capturado, não contabilizado; 400: dados inválidos; 401: token inválido; 403: escopo insuficiente. Protocolo nativo do contador ainda pendente.
